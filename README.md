# Part Manager — Desktop GUI App

Приложение для управления списком компьютерных комплектующих.

### Возможности
- Добавление новых комплектующих.
- Просмотр списка записей.
- Редактирование информации.
- Удаление записей.
- Очистка полей ввода.

### Используемые технологии
- Python
- Tkinter — создание графического интерфейса.
- SQLite3 — хранение данных.

### Запуск проекта
1. Установить Python.
2. Скачать проект.
3. Запустить файл `part_manager.py`.

### Описание
Проект представляет собой простое настольное приложение с графическим интерфейсом, позволяющее удобно управлять информацией о компьютерных комплектующих и хранить её в базе данных SQLite.
